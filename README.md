# MirthXeno

MirthXeno enables real-time data processing through a distributed architecture, scalable message routing via a centralized broker and gateway.

MirthXeno is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/MirthXeno.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

MirthXeno is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
